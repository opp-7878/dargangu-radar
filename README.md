# DargaNGU News Radar

Радар новостей GTA 6: каждые 10 минут, круглосуточно, собирает новости из официальных источников, СМИ, фан-сайтов, Reddit и Telegram, склеивает одну и ту же новость из разных источников в одну историю, оценивает важность и достоверность и шлёт в Telegram-бот:

- 🔴 **ОФИЦИАЛЬНО** — новое от Rockstar (YouTube, Newswire) — сразу, в любое время;
- 🟡 **Новость** — важная история (важность ≥ 80, или ≥ 70 с горячей темой), с 8:00 до 24:00 МСК, ночные — утром;
- ⬆️ — история, которую подтвердили уже 3+ крупных СМИ;
- 🗞 **Дайджест** — в 21:00 МСК, топ-7 за сутки.

Работает на GitHub Actions бесплатно, Mac можно выключить. План целиком — `../OPS/NEWS_RADAR_PLAN.md`.

## Файлы
| Файл | Что это |
|---|---|
| `radar.py` | весь код, без внешних библиотек |
| `sources.json` | источники и их вес — **сюда добавляем новые каналы** |
| `data/news.json` | база историй за 7 дней (её обновляет GitHub после каждого запуска) |
| `.github/workflows/radar.yml` | расписание запуска |

## Добавить Telegram-канал
В `sources.json` скопируй блок `tg_gtavistar`, поменяй `id`, `name` и адрес `https://t.me/s/<имя_канала>`. Работает только с открытыми каналами.

## Уровни достоверности (как в CLAUDE.md §4)
- **CONFIRMED** — есть источник из группы `official`;
- **HIGH CONFIDENCE** — 3+ разных СМИ с весом ≥ 60;
- **PROBABLE** — пишет хотя бы одно СМИ / фан-сайт;
- **SPECULATION** — только Reddit/Telegram, или половина заголовков про слив.

## Этапы
1. ✅ Сборщик + уведомления (этот код).
2. GigaChat: перевод, суть в 2–3 предложениях, пост в стиле канала, черновик сценария.
3. Вкладка «Радар» в дашборде + фирменная карточка-картинка к посту.

## Кнопки постов (с 15.10.2026)
Под каждой карточкой — «📝 Пост» (полный, 800–1300 знаков), «⚡ Срочно» (хук + суть, 200–400), «📋 По пунктам» (много деталей списком).
Нажал → webhook (Vercel, `webhook/`) сразу запускает GitHub Actions, радар через 10–20 с берёт полный текст 1–2 статей, пишет пост через GigaChat и присылает ответом на карточку.
Срочная новость (официальное, или важность ≥85 и тема дата/ПК/трейлер/цена/preload) — короткий пост приходит сразу.
Ночью карточки тоже приходят (QUIET = None в radar.py).
Проверка: Actions → radar → Run workflow → `test_post` (3 формата в лог) или `test_card` (карточка с кнопками в бот), `test_q` — слово из заголовка.
